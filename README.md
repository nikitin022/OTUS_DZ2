# Сайт услуг парикмахера и массажиста

Публичный сайт-визитка мастера, предоставляющего услуги парикмахерского искусства и массажа.

## Возможности
- Перечень и описание услуг, прайс
- Галерея примеров работ и информация о мастере
- Запись на услугу и форма обратной связи
- Контакты, локация и режим работы

## Технологический стек
- **HTML5** — семантическая разметка
- **CSS3** — стилизация (CSS-переменные, БЭМ-подобные классы)
- **JavaScript (ES2020+)** — клиентская логика (ES-модули)

Проект — статический сайт без серверной зависимости.

## Описание проекта и правила разработки
См. [`hw_ai_rules.md`](./hw_ai_rules.md) — свод требований к стеку, архитектуре, стилю кода и стандартам разработки.

## Запуск
1. Откройте `index.html` в браузере (двойной клик), **либо**
2. Запустите локальный сервер и откройте `http://localhost:8000`:
   ```bash
   python -m http.server 8000
   ```
